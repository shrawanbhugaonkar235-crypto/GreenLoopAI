# GreenLoopAI — Real AI Assistant

## Overview
The **GreenLoopAI Assistant** is a real-time conversational agent embedded directly into the application's bottom-right corner. It uses the official OpenAI Python SDK via FastAPI to answer questions about the GreenLoopAI project, waste verification, EPR policies, and general technical inquiries.

## Design Principles
- **No Mock Answers**: Every response is generated by the configured AI model.
- **No Hardcoded Scripting**: No rule-based hardcoded responses or fake typing animations.
- **Stateless Privacy**: Requests use `store=False`. Conversations are held only in runtime client memory during the active session.
- **Strict System Guardrails**: The assistant adheres to dedicated system instructions preventing hallucination of unverified scan records or fabrication of project metrics.

## Supported Capabilities
1. **Project Understanding**: Explains the *Detect → Verify → Reward* lifecycle, GreenCoins economics, and automated EPR compliance proofs.
2. **Context-Aware Assistance**: Interprets the current active view or verified scan result provided explicitly in the request payload.
3. **Technical Assistance**: Answers architectural and engineering questions regarding Python, FastAPI, Java Spring Security, YOLO Computer Vision, OCR, and cybersecurity.

## Error Handling Matrix
| Scenario | Backend Detail Code | User-Facing UI Message |
|---|---|---|
| OpenAI key missing | `AI_SERVICE_NOT_CONFIGURED` | `AI Assistant is not configured.` |
| OpenAI rate limit | `HTTP 429` | `The assistant is temporarily busy. Please try again.` |
| OpenAI network drop | `HTTP 503` | `AI Assistant is temporarily unavailable.` |
| Security gateway rejected | `HTTP 401 / 403` | `Authentication required.` / `You don't have permission to use this feature.` |
| Internal server issue | `HTTP 500` | `AI processing service unavailable.` |
